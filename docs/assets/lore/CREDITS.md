# Scene assets

The six 3D point-cloud scenes are sampled from the public official Arknights: Endfield Lore section. They are game scene artwork, not Bernie’s original projects or skill evidence. All original rights remain with their respective owners.

Reference: https://endfield.gryphline.com/en-us#lore

The local JSON files retain surface samples from the original XYZ point clouds with centered, uniformly scaled coordinates; the portfolio renderer and skill descriptions are local implementations.
