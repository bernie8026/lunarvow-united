CIS222 / WEB DESIGN AND DEVELOPMENT網頁設計與開發

用 HTML 建立清楚嘅頁面結構，用 CSS 排版，並考慮不同螢幕大小下嘅閱讀同導覽。

CIS282 / WEB DEVELOPMENT AND SECURITY網頁開發與安全

喺呢份作品集實踐 JavaScript 互動、表單驗證同安全文字輸出，亦留意外部連結同前端資料處理。

PROGRAMMING / FOUNDATIONS程式與解難基礎

透過 C++、Python 同邏輯練習，學習將問題拆成步驟，再逐步檢查結果。

COMMUNICATION / CREATIVE WORK溝通與數碼敘事
